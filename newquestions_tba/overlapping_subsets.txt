Approach - 

Clearly first we need to find the distribution of the function P(N=|A intersection B| = k).
i.e. lets try and ans the question, whats the prob that the intersection has exactly k elements.

so, naturally, lets choose k elements from the 20 elements, which are definitely common.
20Ck.
 next step? we essentially wish to count how many subsets exist from the remaning 20-k subsets, which have "NOTHING IN COMMON". (then we add these k to both, and can say that this is a valid combination.)

- (end of step)

So, lets look at this subproblem first. Define N(n) = num of ways of choosing 2 mutually exclusive subsets from 1..n 

For this subproblem, I will present 2 lines of thought, both converging to the same answer.. rather elegantly.

First way - 

Say we take some "j" from the (n) for our first subset. the second subset, can be anysubset formed using the remaining n-j.
and this "j" we can vary from 0 to n.

this, sigma (j=0 to n) C(n,j)*(# of subsets made using n-j)
the second term is just 2^(n-j).

thus, (show evaluation of sum, using binomial series.. write 1^j, and show (2+1)^(n))


Second way - 

By logic, lets see every element of the set.. we can either
1. Assign to subset A
2. Assign to subset B
3. Not assign it anywhere (a subset need not have all elements!)

hence 3 options per element. total elements = n .

Thus total 3^n ways.

[both same, shown using different lines of thought..]

now that we have #(split set of n elements into 2 ME subsets) = 3^n.

We use this in our original expression, where n (is equivalent to) 20-k.

Thus, continuing step 1, we have

total ways = 20Ck.(3^(20-k))

denominator? total ways? (2^20 * 2^20) (both subsets have 2^20 options.)

this is our expression for P(N=k).

sanity check, sum should be one. use binomial theorem, 1^k, and show it becomes 4^20/2^40, which is 1.

Then, now that we have distribution of N, we can compute E[X] and E[X^2].

for E[k], we can use the (1+r)^n = sigma(nCr)(r^n), expression, differentiation wrt r on both sides, and get an expression for sigma(r.nCr.a^n-r) types.. which we want for our E[X].

for E[X^2], we can differentiate it again, and derive an expression for that.. show both, or refer them to existing wikipedia results.

and compute Var(X) = E[X^2] - (E[X])^2, and final ans in box as usual.
